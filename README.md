# نظام إدارة مالية الفلج

<img src="icons/icon-192.png" width="96" alt="شعار الفلج">

تطبيق ويب للإدارة المالية للأفلاج العُمانية، بقاعدة بيانات **مشتركة ومحمية** بين المستخدمين المصرّح لهم. يسجّل الواردات والمصروفات، ويصدر السندات والتقارير، وينشئ ملفات PDF ويرسلها عبر واتساب. يعمل على الهاتف والجهاز اللوحي والحاسوب، ويمكن تثبيته كتطبيق، ويعمل بدون إنترنت ثم يزامن عند عودة الاتصال.

## محتويات المشروع

| الملف | الوظيفة |
|---|---|
| `index.html` | التطبيق كاملاً، ومعه إعدادات الاتصال بـ Firebase |
| `firestore.rules` | **قواعد الأمان**، وتُنسخ إلى Firebase (خطوة إلزامية) |
| `manifest.webmanifest` و `sw.js` | التثبيت والعمل بدون إنترنت |
| `icons/` و `screenshots/` | الشعار وصور نافذة التثبيت |
| `firebase.json` | لاستخدام أدوات Firebase مستقبلاً (اختياري) |

---

## الخطوة 1: إعداد Firebase (مرة واحدة)

من [console.firebase.google.com](https://console.firebase.google.com) ← مشروع **falaj-finance**:

1. **Authentication ← Sign-in method:** فعّل **Google** و **Email/Password**.
2. **Authentication ← Settings ← Authorized domains:** اضغط **Add domain** وأضف نطاق GitHub الخاص بك، مثل `اسم-المستخدم.github.io`.
3. **Firestore Database:** إن لم تُنشأ بعد، اضغط **Create database** ثم اختر **Production mode**.
4. **Firestore Database ← Rules:** احذف كل المحتوى الموجود، والصق محتوى ملف `firestore.rules` كاملاً، ثم اضغط **Publish**.
   > ⚠️ بدون هذه الخطوة لن يعمل التطبيق، لأن القاعدة سترفض كل العمليات.

## الخطوة 2: النشر على GitHub Pages

1. ارفع **جميع محتويات المجلد** إلى المستودع (Add file ← Upload files ← Commit).
2. افتح **Settings ← Pages**، ثم اختر `Deploy from a branch` والفرع `main` والمجلد `/ (root)`، واضغط **Save**.
3. بعد دقيقة أو دقيقتين يعمل الرابط: `https://اسم-المستخدم.github.io/اسم-المستودع/`

## الخطوة 3: أول دخول

1. افتح الرابط، واضغط **«الدخول بحساب Google»** باستخدام أحد بريدَي المالكَين:
   - `falajbutin@gmail.com`
   - `hrhalyzeedi@gmail.com`
2. ستفتح شاشة **بيانات الفلج** تلقائياً. أدخل اسم الفلج والولاية واسم الوكيل.
3. أضف المستخدمين من: **الأدوات ← إدارة المستخدمين**.

## المستخدمون والصلاحيات

| الصلاحية | مدير النظام | محاسب | مُطّلع |
|---|:---:|:---:|:---:|
| عرض الأرصدة والسجل والتحليلات والتقارير وPDF وواتساب | ✅ | ✅ | ✅ |
| إضافة المعاملات وتعديلها | ✅ | ✅ | ❌ |
| حذف المعاملات واستعادتها | ✅ | ❌ | ❌ |
| البنود، بيانات الفلج، الرصيد، الترقيم، الاستيراد، النسخ الاحتياطي | ✅ | ❌ | ❌ |
| إدارة المستخدمين | ✅ | ❌ | ❌ |

- **المالكان** (البريدان أعلاه) مديران دائمان، ولا يستطيع أي مدير آخر إيقافهما أو تغيير صلاحيتهما.
- **إضافة مستخدم بحساب Google:** يكتب المدير بريد Gmail ويختار الصلاحية، ثم يدخل الشخص بزر «الدخول بحساب Google».
- **إضافة مستخدم ببريد وكلمة مرور:** يُنشأ الحساب فوراً، ويعرض التطبيق إرسال بيانات الدخول للمستخدم عبر واتساب.
- **الإيقاف وتغيير الصلاحية** يُطبَّقان فوراً على جهاز المستخدم.
- كل معاملة تحفظ **من أضافها ومن عدّلها ومتى**. والمعاملات المحذوفة تبقى في **سجل المحذوفات** ويمكن استعادتها.

## ملاحظات مهمة

- **نقل البيانات القديمة:** إذا كانت لديك معاملات في النسخة السابقة على نفس الجهاز ونفس الرابط، يعرض التطبيق على المدير نقلها من **الإعدادات ← النسخ الاحتياطي**. وإن كانت على جهاز أو رابط آخر، صدّر منها نسخة احتياطية JSON ثم استعدها هنا.
- **الآيفون (التطبيق المثبّت على الشاشة الرئيسية):** قد لا تعمل نافذة الدخول بحساب Google داخل التطبيق المثبّت. في هذه الحالة استخدم الدخول بالبريد وكلمة المرور، أو سجّل الدخول من Safari.
- **العمل بدون إنترنت:** يجب الدخول مرة واحدة على الأقل والإنترنت متصل. بعدها تُحفظ المعاملات على الجهاز وتُرفع تلقائياً عند عودة الاتصال. تظهر نقطة برتقالية على صورة الحساب ما دامت هناك تعديلات لم تُرفع بعد.
- **التكلفة:** الخطة المجانية في Firebase (Spark) تكفي لهذا الاستخدام، ولا تحتاج إلى بطاقة دفع.

## نشر تحديث للتطبيق

1. ارفع ملف `index.html` الجديد مكان القديم.
2. غيّر رقم الإصدار في ملف `sw.js`، مثلاً `const VERSION = 'v2.0.1';`.
3. يظهر للمستخدمين شريط «يتوفر تحديث جديد»، وبياناتهم في القاعدة المشتركة لا تتأثر.
4. إذا تغيّر ملف `firestore.rules`، انسخه مجدداً إلى Firebase واضغط Publish.
