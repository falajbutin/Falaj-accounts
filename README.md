# نظام إدارة مالية الفلج

<img src="icons/icon-192.png" width="96" alt="شعار الفلج">

تطبيق ويب للإدارة المالية للأفلاج العُمانية. يسجّل الواردات والمصروفات، ويصدر سندات القبض والصرف، والتقارير، وملفات PDF، ويرسلها عبر واتساب. يعمل على الهاتف والجهاز اللوحي والحاسوب، **ويمكن تثبيته كتطبيق** يعمل بدون إنترنت.

## محتويات المشروع

| الملف | الوظيفة |
|---|---|
| `index.html` | التطبيق كاملاً |
| `manifest.webmanifest` | بيانات التثبيت: الاسم، الأيقونة، الألوان، الاختصارات |
| `sw.js` | عامل الخدمة: يتيح التثبيت والعمل بدون إنترنت |
| `icons/` | شعار الفلج بكل المقاسات |
| `screenshots/` | صور تظهر في نافذة التثبيت على أندرويد |
| `.nojekyll` | يجعل GitHub Pages يعرض الملفات كما هي |

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub، مثلاً `falaj-finance`، واجعله **Public**.
2. اضغط **Add file ← Upload files**، ثم اسحب **جميع محتويات المجلد** (وليس المجلد نفسه)، بما فيها مجلدا `icons` و`screenshots`، ثم اضغط **Commit changes**.
   > ملف `.nojekyll` مخفي في بعض الأجهزة. إن لم يُرفع فلا مشكلة، فالتطبيق يعمل بدونه.
3. افتح **Settings ← Pages**، واختر من **Source**: `Deploy from a branch`، ثم الفرع `main` والمجلد `/ (root)`، واضغط **Save**.
4. بعد دقيقة أو دقيقتين يظهر الرابط:
   `https://اسم-المستخدم.github.io/falaj-finance/`

## التثبيت على الأجهزة

- **أندرويد (Chrome):** افتح الرابط، ثم اضغط زر **«تثبيت»** الذي يظهر في أعلى التطبيق، أو من قائمة المتصفح ⋮ اختر **«تثبيت التطبيق»**.
- **آيفون / آيباد (Safari):** اضغط زر المشاركة ⬆️ ثم **«إضافة إلى الشاشة الرئيسية»**. التطبيق يعرض هذه الخطوات بنفسه عند الضغط على زر التثبيت.
- **الحاسوب (Chrome / Edge):** اضغط أيقونة التثبيت في شريط العنوان، أو زر **«تثبيت التطبيق»** في القائمة الجانبية.

بعد التثبيت، الضغط المطوّل على الأيقونة في أندرويد يعرض اختصارين: **إضافة وارد** و**إضافة مصروف**.

## ملاحظات مهمة عن البيانات

- البيانات تُحفظ **على الجهاز نفسه** داخل المتصفح، ولا تُرفع إلى GitHub ولا إلى أي خادم.
- كل جهاز له بياناته المستقلة. لنقل البيانات بين الأجهزة استخدم: **الأدوات ← النسخ الاحتياطي ← تصدير**، ثم **استعادة** على الجهاز الآخر.
- **البيانات المسجّلة سابقاً عند فتح الملف مباشرة من الجهاز لن تظهر تلقائياً في الرابط الجديد.** صدّر نسخة احتياطية من النسخة القديمة أولاً، ثم استعدها في التطبيق المنشور.
- **في الآيفون:** التطبيق المثبّت على الشاشة الرئيسية له تخزين منفصل عن Safari. ثبّت التطبيق أولاً، ثم أدخل البيانات أو استعد النسخة الاحتياطية من داخله.
- يُنصح بتصدير نسخة احتياطية بشكل دوري.

## نشر تحديث للتطبيق

1. ارفع ملف `index.html` الجديد إلى المستودع مكان القديم.
2. افتح `sw.js` وغيّر رقم الإصدار في السطر:
   ```js
   const VERSION = 'v1.0.0';   // مثلاً إلى 'v1.0.1'
   ```
3. عند فتح المستخدمين للتطبيق يظهر لهم شريط **«يتوفر تحديث جديد»**. بالضغط على **تحديث** تُحمّل النسخة الجديدة، وتبقى بياناتهم كما هي.
